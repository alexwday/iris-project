2. Database Refresh Process

2.1 Prep Processes

Run these before the main refresh when source files need conversion.

Prep Process Purpose Input → Output Dataiku Notebook
Docx to PDF Converts .docx files to PDF format *_raw/ (.docx) → main folder (.pdf) [link]
Excel to PDF Converts each Excel row into individual PDF documents *_raw/ (.xlsx) → main folder (multiple .pdf) [link]
Vision Prep Extracts text from infographics using vision AI PDF with images → markdown content [link]
Semantic Search EY Prep Converts large EY PDF to markdown and splits into chapters Single PDF → chapter-split JSON [link]
Semantic Search IASB Prep Merges and processes IASB standard PDFs Multiple PDFs → processed standards [link]

2.2 Catalog Search Refresh

For internal databases. Processes PDFs to extract metadata and content sections.

Stage Description Output
Stage 1: Extract & Compare Compares NAS files vs master CSV; identifies new, updated, deleted files 1C_nas_files_to_process.json
Stage 2: Process Documents Extracts content using Azure Document Intelligence Markdown files in 2B_outputs/
Stage 3: Generate Summaries Creates AI summaries (description and usage) using GPT 3A_catalog_entries.json
Stage 4: Update CSV Updates master CSVs with new entries; removes deleted records Updated master_catalog.csv, master_content.csv
Stage 5: Output Final Creates timestamped deployment files; archives run Timestamped CSVs for IT pickup

Dataiku Notebook: [Link to Catalog Search All-Stages]

2.3 Semantic Search Refresh

For external databases. Processes large documents with embeddings for similarity search.

Stage Description Output
Stage 1: Chapter Processing Processes chapter structure with GPT stage1_page_records.json
Stage 2: Section Processing Creates section-level records with GPT summaries stage2_section_records.json
Stage 3: Content Chunking Chunks sections into 500-750 tokens for embedding stage3_chunks.json
Stage 4: Embedding Generation Generates vector embeddings (text-embedding-3-large) stage4_embedded_chunks.json
Stage 5: CSV Export Exports to master CSV; creates deployment copy master_database.csv
Stage 6: Database Upload Uploads to PostgreSQL with pgvector Updated iris_semantic_search table

4. Adding a New Database

  1. Create folder structure on NAS
    • Create input folder: [NAS_BASE_PATH]/[database_name]/
    • If prep needed, create: [NAS_BASE_PATH]/[database_name]_raw/
  2. Add to refresh configuration
    • Edit DOCUMENT_SOURCES in the stage scripts
    • Add line: [database_name],[detail_level]
  3. Run database refresh
    • Execute full refresh in Dataiku
    • Verify database appears in master CSV
  4. Update application code
    • Add database definition to database_statement.py
    • Add routing entry to database_router.py
    • Add test questions to questions_mapping
  5. Configure access
    • Request AD group creation if needed
    • Update environment configuration
  6. Deploy and verify
    • Deploy through standard release process
    • Test sample queries against new database

5. Quarterly Model Testing

Model Risk compliance testing performed at the end of each quarter.

Resources

Test Template (Excel) [link]
Default 50 Test Questions [link]
Tableau Dashboard (Queries & Feedback) [link]
Performance Tracking Table [link]

Process

  1. Prepare test set
    • Start with 50 default test questions
    • Remove 10 questions
    • Replace with top 10 real queries from Tableau (from the quarter)
    • Save updated set as new default in Confluence
  2. Execute testing
    • Enter each question into IRIS UI
    • Copy question + answer into Excel template
    • Rate response quality (1-10 scale)
  3. Aggregate feedback
    • Pull thumbs up/down counts from Tableau for the quarter
  4. Update tracking
    • Insert results into performance tracking table
    • Check for threshold breaches
  5. Submit to Model Risk
    • Complete Model Risk quarterly template
    • Submit by deadline
