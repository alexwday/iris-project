Stage 3: Clarifier Agent

Context sufficiency check — determines if clarifying questions are needed or research can proceed

When is this called? Only when the Router Agent (Stage 1) returns research_from_database. This is the first step of the research path.

Unified Architecture Note: The metadata subagent uses a unified 3-way decision architecture. For each document, it decides: answered (finding from metadata sufficient), irrelevant (not relevant), or needs_deep_research (trigger file research). This eliminates the need for the clarifier to pre-determine research depth.

Decision Logic

LLM chooses request_essential_context when:
  • Time period is ambiguous (e.g., "What's the rate?" without specifying quarter)
  • Business unit/segment unclear (e.g., which LOB or geography)
  • Critical terminology needs clarification
  • Request is too vague to form a research statement
LLM chooses proceed_with_research when:
  • Research question is clear and specific
  • All essential context is provided (time, scope, topic)
  • User explicitly answered a previous clarifying question
  • Request mentions specific documents, rates, or methodologies

The Research Statement

Key Output: When proceeding with research, the output field contains a research statement — a reformulated, clear description of what to search for in the databases.

Research Statement Examples

User Message Generated Research Statement
"What's the CAPM rate for Q2?" "Find the CAPM discount rate methodology and specific rate value for fiscal Q2 2024"
"Show me the loan loss reserve policy" "Locate documentation describing the loan loss reserve policy and calculation methodology"
