Stage 1: Router Agent

First decision point — determines if the request needs database research or can be answered directly

Architecture Flow Diagram

Inputs

conversation: {"messages": [{"role": "user", "content": "..."}]}
token: OAuth token or API key string
↓

Step 1: Load Prompts

Table: iris_prompts
Filter: layer='agent' AND name='router'
Fields: system_prompt, tool_definition, user_prompt
↓

Step 2: Format Conversation

Transform messages array → formatted string
Replace placeholder: {{conversation}}
↓

Step 3: LLM Tool Call

Model: gpt-4.1 (config.MODEL_LARGE)
Temperature: 0.0 (deterministic)
Max tokens: 4,096
Tool: route_query (forced)
↓

Output

"response_from_conversation" → Direct Response Agent
"research_from_database" → Clarifier Agent

Step-by-Step Execution

1
Load Prompts from Database
Parameter Value
Table iris_prompts
Filter layer = 'agent' AND name = 'router'
Fields Retrieved system_prompt, tool_definition, user_prompt

Example Prompt Data

system_prompt: You are a routing agent. Analyze the conversation and determine if the user's request requires database research or can be answered directly from the conversation context. user_prompt: Based on the following conversation, decide how to route this request: {{conversation}} tool_definition: - type: function function: name: route_query parameters: properties: function_name: type: string enum: [response_from_conversation, research_from_database]
2
Format Conversation for Prompt
Parameter Value
Input Format {"messages": [{"role": "user", "content": "..."}, ...]}
Output Format "[ROLE]: content" joined by \n\n
Placeholder {{conversation}} in user_prompt template

Example Transformation

// INPUT: { "messages": [ {"role": "user", "content": "What is the CAPM rate for Q2?"}, {"role": "assistant", "content": "I can help with that."}, {"role": "user", "content": "Please find the documentation."} ] } // OUTPUT: "[USER]: What is the CAPM rate for Q2? [ASSISTANT]: I can help with that. [USER]: Please find the documentation."
3
LLM Tool Call
Parameter Value
Model config.MODEL_LARGE → gpt-4.1
Temperature 0.0 (fully deterministic)
Max Tokens 4,096
Streaming false (wait for complete response)
Tool Name route_query
Tool Choice required (LLM must call this function)

Messages Sent to LLM

[ {"role": "system", "content": "<system_prompt from database>"}, {"role": "user", "content": "<user_prompt with {{conversation}} replaced>"} ]

Tool Definition Sent

[{ "type": "function", "function": { "name": "route_query", "parameters": { "type": "object", "properties": { "function_name": { "type": "string", "enum": ["response_from_conversation", "research_from_database"] } }, "required": ["function_name"] } } }]
4
Parse LLM Response
Parameter Value
Response Location response.choices[0].message.tool_calls[0].function.arguments
Expected Format JSON string: '{"function_name": "..."}'
Valid Values response_from_conversation OR research_from_database

Example LLM Response

response.choices[0].message.tool_calls[0].function.arguments = '{"function_name": "research_from_database"}'

Output

Field Type Possible Values
function_name string "response_from_conversation" or "research_from_database"

What Happens Next

→ response_from_conversation

Go to Direct Response Agent (Stage 2)
Answer directly without database research

→ research_from_database

Go to Clarifier Agent (Stage 3)
Proceed with database research workflow

Decision Logic

LLM chooses response_from_conversation when:
  • Question is a follow-up or clarification
  • Answer is in previous conversation
  • General knowledge question
  • No specific document/data lookup needed
LLM chooses research_from_database when:
  • User asks about specific policies, rates, methodologies
  • Request requires looking up documentation
  • Question references specific time periods, business units
  • Technical/domain-specific information needed
