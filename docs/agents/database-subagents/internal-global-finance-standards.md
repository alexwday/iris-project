# Internal Global Finance Standards Subagent (`iris/src/agents/database_subagents/internal_global_finance_standards/`)

Implementation of the internal database subagent for querying internal RBC Global Finance Standards documents.

## Overview

The Internal Global Finance Standards subagent is one of the standard internal database subagents that query and synthesize research from internal RBC content. This implementation targets the Global Finance Standards database containing international financial reporting standards, policies, and implementation guidance.

## Key Differences

This subagent uses the following specific configurations:
* **DATABASE_NAME**: "internal_global_finance_standards"
* **Content Focus**: Global finance standards and international reporting policies
