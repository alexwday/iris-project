# Jupyter Notebooks (`notebooks/`)

This directory contains Jupyter notebooks used for testing, debugging, analysis, and demonstrating the functionality of the IRIS system.

## Overview

The notebooks collection provides interactive environments for testing IRIS system components, analyzing process monitoring data, exporting database information, and conducting end-to-end pipeline validation. These notebooks serve as essential tools for development, debugging, analysis, and operational monitoring of the IRIS system. Each notebook is designed for specific use cases ranging from system testing to data export and performance analysis.

## Key Components

* **`test_notebook.ipynb`**: Primary end-to-end testing environment for IRIS query pipeline validation
* **`db_export_tool.ipynb`**: Database export utility for data analysis and backup purposes
* **`db_export_standalone_tool.ipynb`**: Standalone version of database export functionality
* **`process_monitor_analysis.ipynb`**: Process monitoring data analysis and visualization tools
* **`process_monitor_insert_standalone.ipynb`**: Standalone process monitoring data insertion utilities

## Core Functions/Classes

### Primary Testing Notebook (`test_notebook.ipynb`)

#### Purpose
Provides the main end-to-end testing environment for validating the complete IRIS query pipeline and agent interactions.

#### Key Features
* Complete pipeline testing with customizable conversation inputs
* Agent workflow validation and debugging capabilities
* Response analysis and performance monitoring
* Interactive query experimentation and result inspection

#### Usage
Modify the `conversation` variable to input test queries and execute cells to validate system responses

### Database Export Tools

#### `db_export_tool.ipynb`
**Purpose**: Database export utility for data analysis, backup, and sharing purposes with integrated functionality

#### `db_export_standalone_tool.ipynb`  
**Purpose**: Standalone version of database export functionality for independent operation without full system dependencies

#### Key Features
* Data extraction from PostgreSQL databases
* Export formatting for analysis and backup purposes
* Configurable export parameters and filtering options

### Process Monitoring and Analysis

#### `process_monitor_analysis.ipynb`
**Purpose**: Analysis and visualization tools for process monitoring data generated by the IRIS system

#### `process_monitor_insert_standalone.ipynb`
**Purpose**: Standalone utilities for inserting and managing process monitoring data

#### Key Features
* Performance data visualization and trend analysis
* Process execution tracking and timing analysis
* System performance monitoring and optimization insights
