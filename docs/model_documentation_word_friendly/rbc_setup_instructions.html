RBC Environment Setup for IRIS Model

This document outlines the essential steps for running the IRIS model in an RBC production environment. These instructions assume you have access to the required RBC systems and authentication credentials.

System Requirements

  • RBC-approved Python environment (3.9+)
  • Access to the maven-finance PostgreSQL database
  • Appropriate network permissions for API access
  • RBC OpenAI API credentials

Environment Setup Process

Step 1: Clone the Repository
Clone the IRIS repository from the RBC internal GitLab to your designated workspace. Contact the IRIS project team for repository access if needed.

Step 2: Database Connection
The IRIS model connects to the maven-finance database. Ensure your RBC network credentials have been granted access to this database. The system will automatically use RBC database parameters when deployed in the production environment.

Step 3: Authentication Configuration
RBC environments use OAuth for API authentication. Your RBC credentials will be used to obtain the necessary OAuth tokens. Confirm with your IT administrator that your account has been granted the appropriate permissions for the OpenAI API service.

Step 4: Model Deployment
The model deploys through the Maven UI framework. Coordinate with the Maven team to ensure the IRIS API endpoints are correctly registered in the Maven service catalog.

Running the Model

In the RBC environment, the IRIS model runs as an API service accessed through the Maven UI. End users do not need to interact directly with the Python code or database. Simply access the Maven interface using your RBC credentials and navigate to the IRIS service.

To run queries through IRIS:

  1. Log into the Maven dashboard with your RBC credentials
  2. Navigate to the Finance Services section
  3. Select the IRIS assistant
  4. Enter your finance or accounting policy query in the provided interface

Troubleshooting

If you encounter issues accessing IRIS through the Maven interface:

  • Verify your RBC network credentials are active and not expired
  • Confirm your account has been granted access to the IRIS service
  • Check with the RBC IT Service Desk if the Maven UI services are operational
