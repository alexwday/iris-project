Appendix B: Running the Model

This appendix provides instructions for installing, configuring, and running the IRIS (Intelligent Retrieval & Interaction System) model. The instructions assume a basic familiarity with command-line interfaces, Python, and database management.

System Requirements

Before proceeding with the installation, ensure your system meets the following requirements:

  • Python 3.9 or higher
  • PostgreSQL database server (latest stable version recommended)
  • Minimum 8GB RAM (16GB recommended for optimal performance)
  • At least 1GB of free disk space
  • Internet access for downloading dependencies and connecting to LLM APIs
  • Appropriate API keys for OpenAI

Installation Procedure

1. Clone the Repository

Begin by cloning the repository to your local machine:

git clone <repository-url>
cd iris-project

2. Database Setup

The IRIS model requires a PostgreSQL database to store document catalogs, content, and process monitoring logs.

  1. Create a PostgreSQL database named maven-finance
  2. Apply the database schema using the provided SQL file:
psql -d maven-finance -f postgres_schema.sql

Alternatively, you can create the database and apply the schema using the PostgreSQL administration tool of your choice.

3. Python Environment Setup

It is recommended to use a virtual environment to manage dependencies:

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

4. Install Dependencies

Install the required Python packages using pip:

# Install core dependencies
pip install -e .

# Install development tools (optional, for contributing)
pip install -e ".[dev]"

This will install all necessary dependencies as specified in setup.py, including:

  • openai - For LLM API connections
  • requests - For HTTP requests
  • cryptography - For secure handling of credentials
  • psycopg2-binary - For PostgreSQL database connectivity
  • jupyter - For running notebooks

5. Configuration

Update the database configuration settings in iris/src/initial_setup/db_config.py to match your PostgreSQL setup:

LOCAL_DB_PARAMS = {
    "host": "localhost",
    "port": "5432",
    "dbname": "maven-finance",
    "user": "your_username",
    "password": "your_password",  # Use appropriate credentials
}

If you're running in a production environment, you'll also need to configure OAuth settings and SSL certificates as needed.

Running the Model

1. Using Jupyter Notebooks

The simplest way to run and interact with the IRIS model is through the provided Jupyter notebooks:

# Start Jupyter Notebook server
jupyter notebook

Navigate to the notebooks/ directory and open test_notebook.ipynb. This notebook provides a basic interface for interacting with the model.

To customize queries, modify the conversation variable in the notebook:

conversation = {
    "messages": [
        {"role": "system", "content": "You are a helpful assistant specialized in accounting."},
        {"role": "user", "content": "Your query here"}
    ]
}

Execute the notebook cells to see the model in action.

2. Monitoring Execution

The IRIS model includes comprehensive logging and process monitoring. Logs will be displayed in the notebook output, showing the execution path through various agents.

For more detailed analysis of performance and execution patterns, refer to the process_monitor_analysis.ipynb notebook, which provides visualizations and statistical analysis of system performance metrics.

Troubleshooting

If you encounter issues when running the model, check the following:

  1. Database Connection: Ensure PostgreSQL is running and accessible, and that the credentials in db_config.py are correct.
  2. API Credentials: Verify that API keys for OpenAI are correctly configured.
  3. Virtual Environment: Make sure the virtual environment is activated before running notebooks or scripts.
  4. Required Tables: Confirm that all required database tables have been created using the postgres_schema.sql file.

For specific error messages, refer to the logs displayed in the notebook output or console.

Maintenance and Updates

To keep the IRIS model up-to-date:

  1. Regularly pull updates from the repository
  2. Update dependencies as needed: pip install -e . --upgrade
  3. Check for and apply any database schema updates

The model's performance can be enhanced by regularly updating the document catalog and content tables with the latest financial and accounting policies.
