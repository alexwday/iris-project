Appendix B: Running the Model

The IRIS model requires Python 3.9+ and PostgreSQL. Begin by cloning the repository and creating a virtual environment with python -m venv venv, then activate it and install dependencies using pip install -e . and pip install -e ".[dev]". Create a PostgreSQL database named maven-finance and initialize it with the schema in postgres_schema.sql.

For local development, update database settings in iris/src/initial_setup/db_config.py with your credentials. For RBC environment deployment, modify the RBC_DB_PARAMS dictionary in the same file, set ENVIRONMENT = "rbc", and configure OAuth settings in iris/src/initial_setup/oauth/oauth_settings.py.

To test the model, run jupyter notebook and open notebooks/test_notebook.ipynb. Modify the conversation variable to test different queries. The notebook provides a streaming interface to see the complete agent pipeline in action, with logs showing the execution path. If you encounter connection issues, verify that PostgreSQL is running and your credentials are correct.

For issues specific to the RBC environment, ensure your network credentials have access to the required resources and that OAuth settings are properly configured. Regular database refreshes will ensure the model remains current with the latest financial and accounting policies.
